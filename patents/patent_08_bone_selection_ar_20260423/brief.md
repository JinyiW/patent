# 基于自回归Transformer的骨骼选择与权重解码网络技术交底书

## 一、发明名称

基于沙漏自回归Transformer与级联权重解码器的三维角色骨骼蒙皮方法及系统

## 二、技术领域

本发明涉及计算机图形学和深度学习领域，具体涉及一种基于自回归生成模型的三维角色骨骼蒙皮权重预测方法。该方法通过自回归Transformer网络逐顶点生成骨骼选择序列，再经级联权重解码器将离散骨骼选择转化为连续蒙皮权重，实现端到端的高精度自动蒙皮。本发明尤其适用于游戏、影视动画、虚拟数字人等场景中大规模三维角色的自动骨骼绑定与蒙皮权重分配。

## 三、背景技术

### 3.1 技术背景

在三维角色动画制作中，骨骼蒙皮（Skinning）是将网格顶点与骨骼关节进行绑定的关键步骤。每个顶点需要被分配到若干相关骨骼，并为每根骨骼赋予相应的蒙皮权重，使得角色网格能够随骨骼运动而自然变形。传统方法依赖专业美术人员手工刷权重，效率低下且难以保证一致性。

现有自动蒙皮方法主要包括：

1. **基于热扩散的方法**：以Pinocchio为代表，通过在网格体积上求解热传导方程得到权重场。该方法计算简洁，但对复杂拓扑结构（如衣物褶皱、多层嵌套结构）的适应性较差，且无法学习数据驱动的先验知识。

2. **基于回归的深度学习方法**：直接将顶点和骨骼特征通过前馈网络映射到蒙皮权重矩阵。此类方法虽然能够利用数据驱动的先验，但通常将所有顶点的权重作为整体一次性输出，忽略了顶点间骨骼选择的依赖关系，且难以处理不同网格骨骼数量变化的问题。

3. **基于编码器-解码器的方法**：将输入特征编码为潜在空间表示后再解码为权重。这类方法在表达能力上有一定优势，但在骨骼选择这一离散决策问题上，回归范式的表达力受限，无法自然地建模顶点间骨骼选择的条件依赖关系。

### 3.2 现有技术的不足

现有方法存在以下主要缺陷：

**（1）缺乏骨骼选择的条件依赖建模**：三维角色的蒙皮权重分配本质上是一个结构化决策问题——某个顶点的骨骼选择往往与其邻近顶点的选择高度相关（例如，手臂上相邻顶点通常选择相同的骨骼子集）。现有回归方法独立预测每个顶点的权重，无法捕获这种空间依赖关系。

**（2）骨骼选择与权重回归耦合**：现有方法通常将骨骼选择（哪些骨骼对该顶点有影响）与权重大小的回归混为一谈。这导致在骨骼数量较多时，模型需要在大量候选骨骼中同时完成选择和回归两个任务，准确率下降。

**（3）缺乏多样性采样能力**：基于回归的方法只能给出单一确定性输出，无法产生多个候选方案供下游选择或人工审阅。这限制了将蒙皮权重预测与强化学习（如DPO偏好优化）等高级训练范式结合的可能性。

**（4）对变长序列的处理能力不足**：不同网格的顶点数量差异悬殊（从几百到数十万），且每个顶点关联的骨骼数也不固定。现有方法通常采用固定维度的输出层，对变长问题的适应性较差。

## 四、发明内容

### 4.1 发明目的

本发明旨在提供一种基于自回归生成模型的骨骼选择与权重解码方法，具体目的包括：

1. 将骨骼蒙皮问题重新建模为自回归序列生成问题，使模型能够捕获顶点间骨骼选择的条件依赖关系；
2. 将骨骼选择与权重回归解耦为两阶段级联结构，各自专注于自身任务，提升整体精度；
3. 通过自回归生成框架天然支持多样性采样，为后续DPO偏好优化和强化学习提供基础架构；
4. 通过滑动窗口注意力和沙漏Transformer结构实现对超长变长序列的高效处理。

### 4.2 技术方案概述

本发明包含两个核心网络：

**骨骼选择网络（BoneSelectionNet）**：基于沙漏自回归Transformer的骨骼选择生成模型。该网络将每个三维网格的骨骼选择问题转化为一个受控的自回归序列生成任务——将网格中所有顶点的骨骼选择展平为一维token序列，通过自回归的方式逐token生成，从而在建模过程中自然地利用前序顶点的骨骼选择作为条件信息。

**权重解码网络（Weight Decoder）**：接收骨骼选择网络输出的离散骨骼选择结果，结合网格和骨骼的几何特征，通过注意力机制将离散选择转化为连续蒙皮权重。

两个网络级联工作：骨骼选择网络首先确定每个顶点应由哪些骨骼控制，权重解码网络再确定每根骨骼对该顶点的具体影响程度。这种解耦设计使得骨骼选择网络可以作为生成模型独立采样多个候选方案，为后续偏好优化提供多样性基础。

## 五、技术方案详述

### 5.1 系统总体架构

本发明的完整推理流程如下：

```
输入: 三维网格（顶点坐标、法线）、骨骼关节（位置、层次结构）
                    ↓
        ┌─────────────────────────┐
        │   特征编码器（冻结）       │
        │  Mesh-Joints Encoder    │
        │  (可选) PartField Encoder│
        └────────────┬────────────┘
                     ↓
        vertex_features [B, V, D_v]
        bone_features   [B, J, D_b]
        context         [B, J+2, D_c]
                     ↓
        ┌─────────────────────────┐
        │   骨骼选择网络（可训练）    │
        │   BoneSelectionNet      │
        │   沙漏自回归Transformer    │
        └────────────┬────────────┘
                     ↓
        token序列 → 反向标记化 → selected_bones [B, V, K]
                     ↓
        ┌─────────────────────────┐
        │   权重解码网络（冻结）      │
        │   Weight Decoder        │
        └────────────┬────────────┘
                     ↓
        skinning_weights [B, V, J]
```

其中B为批次大小，V为顶点数，J为骨骼关节数，K为每个顶点最大关联骨骼数（典型值为12），D_v、D_b、D_c分别为顶点特征维度、骨骼特征维度和上下文维度。

### 5.2 序列标记化方案

本发明的核心创新之一是将三维网格的骨骼选择问题转化为一维序列生成问题。具体地，定义一套专用的标记（Token）词表：

**特殊标记**：
- PAD（ID=0）：填充标记，用于对齐变长序列
- BOS（ID=1）：序列起始标记，在序列开头重复bos_len次（典型值2次）
- EOS（ID=2）：序列结束标记，在序列末尾重复eos_len次（典型值2次）
- SEP（ID=3）：顶点分隔标记，标识不同顶点之间的边界

**骨骼标记**：
- 每根骨骼对应一个标记，ID = 骨骼索引 + 4

由此，词表大小 = 骨骼数量 + 4，随输入骨骼数量动态变化。

**序列编码规则**：

对于一个拥有V个顶点、J根骨骼的三维网格，其骨骼选择序列的格式为：

```
[BOS] [BOS] bone_a1 bone_a2 ... [SEP] bone_b1 bone_b2 bone_b3 ... [SEP] ... [EOS] [EOS]
 ↑          ├───顶点0的骨骼───┤       ├────顶点1的骨骼────┤              ↑
起始标记     按权重大小降序排列       每个顶点最多K根骨骼           结束标记
```

每个顶点关联的骨骼按蒙皮权重从大到小排列，顶点之间以SEP标记分隔。这种线性化策略使得模型可以利用自回归机制学习顶点之间的骨骼选择依赖关系——在生成第i个顶点的骨骼选择时，模型已经"看到"了前i-1个顶点的选择结果。

**标记化方法的关键步骤**：

1. **提取非零骨骼**：对每个顶点，从蒙皮权重矩阵中提取权重大于零的骨骼索引，按权重降序排列，保留前K个（K为超参数，典型值12）。

2. **构建token序列**：将所有顶点的骨骼列表用SEP标记连接，首尾加上BOS和EOS标记。同时生成与token序列等长的vertex_ids数组，记录每个token所属的顶点索引（特殊标记对应-1）。

3. **滑动窗口切割**：由于三维网格的顶点数可达数万甚至数十万，完整序列长度可能超过数十万token。为适应Transformer的计算限制，采用基于分隔符对齐的滑动窗口切割策略。该策略在预设窗口长度（典型值8000 token）附近搜索最近的SEP标记作为切割点，确保每个窗口包含完整的顶点骨骼组。支持随机偏移和均匀分割两种窗口采样策略。

4. **训练标签构造**：采用经典的自回归标签——输入序列右移一位作为目标序列，特殊标记位置使用忽略索引（CROSS_ENTROPY_IGNORE_IDX = -100）不参与损失计算。

**反向标记化**：推理时将生成的token序列还原为骨骼选择矩阵。跳过特殊标记和填充，根据SEP标记将序列切分为各顶点的骨骼组，每组去重后填充到固定长度K，缺失位用-1标记。

### 5.3 骨骼选择网络架构

#### 5.3.1 整体结构

骨骼选择网络（BoneSelectionNet）是本发明的核心组件。其继承自ModelMixin和ConfigMixin，具有完整的模型保存和加载能力。

网络的主要超参数如下（以生产配置为例）：
- 隐藏维度（dim）：2048
- 上下文维度（context_dim）：256
- 注意力头数（n_heads）：8
- KV头数（n_kv_heads）：8
- 网络深度（depth）：16层（或沙漏布局[pre, valley, post]）
- 沙漏压缩因子（shorten_factor）：4
- 旋转位置编码频率（theta_rotary_emb）：1,000,000
- 前馈网络扩展比（ffn_multiple）：4
- 交叉注意力间隔（condition_interval）：4
- 滑动窗口长度（max_sliding_tokens）：8000
- 最大推理token数（max_infer_tokens）：80000
- 顶点特征维度（vertex_feature_dim）：704

#### 5.3.2 双通道混合token嵌入

本发明提出一种新颖的双通道混合token嵌入策略，将骨骼特征和顶点特征在嵌入空间中进行结构化融合。

对于维度为dim的嵌入向量，其左半部分（0 : dim/2）和右半部分（dim/2 : dim）分别承载不同类型的特征信息：

**特殊标记嵌入**：PAD、BOS、EOS、SEP四种特殊标记通过专用的可学习嵌入层（Embedding(4, dim)）映射到完整的dim维空间。

**骨骼标记嵌入**：对于表示骨骼选择的标记（ID ≥ 4），嵌入向量的构造方式为：
- 右半部分（dim/2 : dim）：通过线性投影层将骨骼特征从context_dim维投影到dim/2维，即 bone_up_layer: context_dim → dim/2
- 左半部分（0 : dim/2）：通过线性投影层将当前顶点特征从vertex_feature_dim维投影到dim/2维，即 vertex_up_layer: vertex_feature_dim → dim/2

**分隔标记与末尾BOS的特殊处理**：对SEP标记和最后一个BOS标记，先将其完整dim维嵌入通过降维层（dim_down_layer: dim → dim/2）压缩到左半部分，为后续顶点特征的注入腾出右半空间。

这种双通道设计有两个重要优势：
1. 骨骼特征和顶点特征在嵌入空间中保持相对独立，避免信息干扰；
2. 每个token同时携带"该位置属于哪个顶点"和"该位置选择了哪根骨骼"两类信息，使Transformer能够同时利用空间上下文和骨骼特征进行推理。

#### 5.3.3 沙漏Transformer主干

骨骼选择网络的核心计算由沙漏型因果Transformer（HourglassCasualSlidingTransformer）承担。该结构将经典Transformer与多分辨率处理相结合，在保持因果性的同时提升对长序列的处理效率。

**沙漏结构的三阶段处理流程**：

```
输入 hidden_states [B, L, D]
           ↓
   ┌── Pre-Transformer ──┐     （pre_layers_depth层）
   │  滑动窗口因果自注意力   │     每condition_interval层包含一次交叉注意力
   │  + 交叉注意力融合      │
   └──────────┬───────────┘
              ↓
   ┌── 线性下采样 ──────────┐     序列长度: L → L/s（s为压缩因子，典型值4）
   │  LinearDownsample      │     将相邻s个token合并为1个
   └──────────┬───────────┘
              ↓
   ┌── Valley-Transformer ──┐     （valley_depth层，处理压缩后的序列）
   │  在1/s分辨率上进行注意力  │     滑动窗口也相应缩短为max_window_len/s
   └──────────┬───────────┘
              ↓
   ┌── 线性上采样 ──────────┐     序列长度: L/s → L
   │  LinearUpsample        │     将1个token展开为s个
   └──────────┬───────────┘
              ↓
   ┌── 因果位移 ────────────┐     左移(s-1)个位置，保持因果对齐
   │  casual_shift          │     确保上采样后的token不包含未来信息
   └──────────┬───────────┘
              ↓
   ┌── 残差连接 ────────────┐     valley_output + pre_output（残差分支）
   └──────────┬───────────┘
              ↓
   ┌── Post-Transformer ──┐      （post_layers_depth层）
   │  滑动窗口因果自注意力   │      每condition_interval层包含一次交叉注意力
   │  + 交叉注意力融合      │
   └──────────┬───────────┘
              ↓
   输出 [B, L, D]（经RMS归一化）
```

**线性下采样（LinearDownsample）**：将相邻s个token拼接为s*dim维向量，再通过线性层投影回dim维。即 Reshape[B, L, D] → [B, L/s, s*D] → Linear → [B, L/s, D]。

**线性上采样（LinearUpsample）**：通过线性层将dim维扩展为s*dim维，再reshape为s个token。即 Linear[B, L/s, D] → [B, L/s, s*D] → Reshape → [B, L, D]。

**因果位移（Causal Shift）**：上采样后需要进行因果位移以保持自回归的因果性。具体地，在序列左端填充(s-1)个零向量，右端截去(s-1)个位置，确保每个位置的信息仅来自其之前的token。

**路由缓存（Routing Cache）**：在自回归推理阶段，沙漏结构面临特殊挑战——当逐token生成时，新token可能不满足压缩因子s的整除要求。本发明通过路由缓存机制解决此问题：
- 每当积累足够s个新token时，执行一次完整的下采样-valley处理-上采样流程，并将结果存入路由缓存；
- 当新token不满足整除要求时，直接从路由缓存中检索之前缓存的结果，与Pre-Transformer的输出进行残差连接。

这种设计使沙漏Transformer能够在逐token自回归推理时保持高效，避免每步都重新计算整个valley分支。

**递归嵌套**：valley分支本身可以是另一个沙漏Transformer，实现多级层次化压缩。例如可以配置三级沙漏结构[6, [3, 4, 3], 6]，其中valley内部再嵌套一层更深的压缩。

#### 5.3.4 滑动窗口因果自注意力

每个Transformer Block内部的自注意力采用滑动窗口机制（SlidingCacheAttention），支持处理任意长度的序列。

**旋转位置编码（RoPE）**：
采用LLaMA风格的旋转位置编码。对于注意力头维度head_dim，预计算频率表：

```
freqs = 1 / (theta^(2i/head_dim)), i = 0, 1, ..., head_dim/2 - 1
freqs_cis[pos] = exp(i * pos * freqs)    （复数极坐标形式）
```

其中theta = 1,000,000（大频率基数），确保超长序列的位置编码不产生混淆。查询和键向量通过与频率表的复数乘法实现旋转。

**QK归一化**：可选地对查询和键应用RMS归一化（在旋转编码之前），稳定注意力计算中的数值范围，防止attention logit的极端值。

**分组查询注意力（GQA）**：键和值的头数（n_kv_heads）可以少于查询头数（n_heads），通过repeat_kv操作将KV头重复匹配查询头数。当n_heads = n_kv_heads时退化为标准多头注意力。

**KV缓存管理**：推理时采用环形缓冲区（Ring Buffer）管理KV缓存。当缓存长度超过滑动窗口大小时，自动丢弃最早的KV对。支持beam search场景下的缓存重排。

**注意力计算后端**：
- 优先使用Flash Attention 2实现高效的因果注意力计算
- 当序列长度超过滑动窗口时退化为PyTorch SDPA，并使用LowerTriangularFromBottomRightLocalAttentionMask生成局部注意力掩码
- 推理时单token查询（q_len=1）且KV长度未超窗口时可跳过因果掩码以加速

#### 5.3.5 稀疏交叉注意力融合

骨骼选择网络通过交叉注意力机制将外部上下文信息注入生成过程。交叉注意力并非在每层都启用，而是每隔condition_interval层（典型值4）启用一次，以平衡计算效率和信息融合充分性。

**上下文构成**：
```
context = [bone_features, vertex_global_feature, skeleton_global_feature, max_bones_count_emb]
形状: [B, J+3, D_c]
```

其中：
- bone_features: 每根骨骼的特征向量（由预训练的Mesh-Joints编码器提取）
- vertex_global_feature: 网格全局特征的聚合表示
- skeleton_global_feature: 骨骼层次结构的全局特征
- max_bones_count_emb: 最大骨骼数的正弦嵌入（通过DiscreteValueEmbedding模块将离散整数映射为连续向量）

**交叉注意力层**：采用与自注意力相同的QKV线性投影结构，但Query来自token嵌入，Key和Value来自上下文。同样支持GQA和QK归一化。

#### 5.3.6 输出层与logit计算

网络的最终输出是每个token位置上所有候选标记的得分（logit）。计算方式采用双线性打分机制：

1. 构建候选特征矩阵：将4个特殊标记的嵌入与所有骨骼的投影特征拼接

```
special_embeddings = Embedding(4, dim)   → [4, dim]
bone_projections = dim_up_layer_2(bone_up_layer(bone_features))  → [J, dim]
combined_features = [special_embeddings; bone_projections]  → [J+4, dim]
```

2. 计算注意力得分：

```
logits = hidden_states @ combined_features^T / sqrt(dim)
形状: [B, L, J+4]
```

此设计使得输出词表大小自动适应输入骨骼数量的变化，无需固定大小的分类头。

#### 5.3.7 Transformer Block详细结构

每个Transformer Block包含三个子模块，均采用Pre-Norm + 残差连接模式：

```
hidden = hidden + SlidingCacheAttention(RMSNorm(hidden))          // 因果自注意力
hidden = hidden + CrossAttention(RMSNorm(hidden), context)         // 交叉注意力（可选）
hidden = hidden + SwiFeedForward(RMSNorm(hidden))                  // 前馈网络
```

**前馈网络（SwiFeedForward）**：采用SiLU门控结构（与LLaMA相同），包含三个线性投影层：

```
output = W2(SiLU(W1(x)) * W3(x))
其中 W1, W3: dim → dim*ffn_multiple
     W2: dim*ffn_multiple → dim
```

**参数初始化**：支持两种策略：
- 深度依赖初始化：标准差 = 0.02 / sqrt(2 * (layer_id + 1))，越深的层初始化越小
- 固定初始化（DeepSeek V3风格）：所有参数标准差 = 0.006

**RMS归一化**：所有归一化层均使用RMSNorm（eps=1e-6），相比LayerNorm减少计算开销。

### 5.4 自回归推理与采样策略

#### 5.4.1 自回归生成流程

推理阶段，骨骼选择网络以自回归方式逐token生成骨骼选择序列。完整流程如下：

1. **初始化**：以BOS标记启动，初始化KV缓存。

2. **BOS填充阶段**：前bos_len-1步输出BOS标记（不进行采样），为模型提供启动上下文。

3. **自回归采样循环**：从第bos_len步开始：
   - a. 取最后一个token作为输入，通过模型获取logits
   - b. 对logits进行Top-K过滤（保留累积概率90%的候选项）
   - c. 应用温度缩放后执行多项式采样
   - d. 计算下一个token的顶点归属（vertex_id）
   - e. 当某顶点已生成topk_num个骨骼标记时，自动插入SEP并转入下一个顶点
   - f. 当所有顶点处理完毕时，生成EOS标记并终止

4. **反向标记化**：将生成的token序列解码为骨骼选择矩阵 [B, V, K]。

#### 5.4.2 顶点追踪机制

自回归生成过程中，需要实时追踪当前正在处理的顶点及已生成的骨骼数量。本发明维护以下状态变量：

- current_vertex_count [B]：当前已完成的顶点数
- current_vertex_bone_count [B]：当前顶点已生成的骨骼数
- vertex_ids [B, L]：每个token对应的顶点索引

顶点ID的计算规则如下：
- BOS标记：vertex_id = -1
- 最后一个BOS标记：vertex_id = 0（标记第一个顶点的开始）
- 骨骼标记：vertex_id = current_vertex_count
- SEP标记或骨骼数达上限：current_vertex_count += 1，vertex_id = 新顶点索引
- EOS标记：vertex_id = -1

这种追踪机制确保模型在每个时刻都能准确获取当前顶点的特征信息用于嵌入计算。

#### 5.4.3 Beam Search解码

本发明支持束搜索（Beam Search）解码策略，用于寻找全局最优的骨骼选择方案。

**束搜索流程**：
1. 将输入复制beam_num份（典型值5-10）
2. 每步对所有beam的logits进行对数概率打分
3. 从所有beam的所有候选中选取得分最高的beam_num个假设
4. 重排KV缓存以匹配新的beam索引
5. 已产生EOS的beam不再参与后续评分
6. 最终从所有假设中选择得分最高的作为最终输出

束搜索还利用BeamHypotheses数据结构管理已完成的假设序列，支持对完成序列的去重和排序。

#### 5.4.4 多样性采样与DPO基础

本发明的自回归生成框架天然支持多样性采样，这是未来进行DPO（Direct Preference Optimization）偏好优化的关键基础设施。

**多样性采样能力**：
- 通过调节采样温度（temperature），可以控制生成的随机性和多样性
- 低温度（如0.3）产生接近贪婪解的确定性输出
- 高温度（如1.0-1.5）产生多样化的候选方案
- Top-K过滤确保采样不会产生极不合理的骨骼选择

**DPO强化学习接口设计**：
- 对同一输入网格，可以通过不同的随机种子或温度参数采样多个骨骼选择方案
- 每个方案经权重解码后可以计算客观质量指标（如蒙皮权重L1距离、骨骼选择准确率）
- 根据质量指标构建偏好对（preferred vs. rejected），用于DPO训练
- 自回归模型的对数概率输出（log_softmax(logits)）直接作为DPO策略的对数似然项

这种设计使骨骼选择模型从单纯的判别/回归模型升级为可进行偏好对齐的生成模型，为蒙皮质量的持续优化提供了范式性的方法论改进。

### 5.5 权重解码网络

权重解码网络接收骨骼选择网络的输出，将离散的骨骼选择转化为连续的蒙皮权重。本发明涉及多种权重解码器实现：

#### 5.5.1 GV4权重解码器（生产部署方案）

GV4权重解码器是当前生产环境中使用的权重解码方案。其核心架构参数如下：

- 位置编码分辨率（positional_res）：10
- 法线编码分辨率（normal_res）：4
- 局部特征维度（local_dim）：1536
- 编码器前馈维度（encoder_dim_feedforward）：2048
- 编码器注意力头数（encoder_num_heads）：8
- 距离TopK骨骼数（dist_topk_num_bones）：60
- TopK段数（topk_segments_num）：16
- 最小/最大选择TopK骨骼数（min/max_select_topk_bones）：16
- 局部编码器深度（local_encoder_depth）：30层
- 段编码器深度（segment_encoder_depth）：24层
- 最终编码器深度（final_encoder_depth）：24层
- 段模式（segment_mode）：pair_varlen
- 骨骼组数（skeleton_group_num）：5
- 关节标签维度（joint_label_dim）：29

**工作流程**：
1. 接收骨骼选择矩阵 [B, V, K] 和原始网格/骨骼几何数据
2. 对骨骼选择结果进行预处理——将-1填充位替换为未选中的骨骼索引
3. 通过多层次的局部-段-全局注意力编码器处理
4. 输出对数概率 predict_log_prob [B, V, J]
5. 取指数 exp(log_prob) 得到最终蒙皮权重
6. 阈值过滤：权重 < 1e-4 的置零

该解码器采用稀疏注意力设计，使用DGL库实现的稀疏注意力机制，有效处理顶点-骨骼间的稀疏交互关系。

#### 5.5.2 双交叉注意力VAE解码器（研究方案）

另一种更具表达力的解码器方案基于变分自编码器（VAE）架构，通过双交叉注意力机制实现从固定维度潜在空间到变维度权重矩阵的映射。

**架构参数**：
- 宽度（width）：256
- 注意力头数（heads）：8
- 自注意力层数（num_decoder_self_attn_layers）：8
- 顶点精化层数（num_decoder_vertex_refine_layers）：2
- 骨骼精化层数（num_decoder_bone_refine_layers）：2
- 输出投影维度（output_projection_dim）：128
- 傅里叶特征频率数（num_freqs）：8
- 输出激活（output_activation）：sigmoid / softmax / exp

**处理流程**：

```
潜在向量 z_hidden [L, D]
           ↓
   自注意力栈（8层）
           ↓
        z_dec [L, D]
           ↓
   ┌──────┴──────┐
   ↓              ↓
顶点分支         骨骼分支
   ↓              ↓
傅里叶嵌入        傅里叶嵌入
(pos + normals)  (skeleton_pos)
   ↓              ↓
线性投影 → [N,D]  线性投影 → [B,D]
   ↓              ↓
交叉注意力        交叉注意力
(Q=顶点, KV=z)   (Q=骨骼, KV=z)
   ↓              ↓
                自注意力精化(2层)
   ↓              ↓
   └──交叉注意力──┘
   (Q=顶点, KV=骨骼)
           ↓
    顶点自注意力精化
           ↓
   双线性输出: v_out [N, D_out] @ b_out [B, D_out]^T / sqrt(D_out)
           ↓
     权重矩阵 [N, B]
```

**双线性分解输出层**：该设计的核心创新是通过分解的双线性运算生成任意大小的N×B权重矩阵。顶点分支输出v_out [N, D_out]和骨骼分支输出b_out [B, D_out]的外积构成最终权重矩阵，避免了直接生成大矩阵的内存和计算开销。

#### 5.5.3 自回归权重解码器（研究方案）

另一种研究中的方案采用逐点自回归解码，使用棍断（Stick-Breaking）离散化方法将连续权重转化为离散bin序列。

**棍断离散化**：
将归一化后的蒙皮权重视为概率分布，通过棍断过程将连续权重分配转化为一系列离散的"选择-权重"对。每步选择一根骨骼并分配相对剩余权重的比例，直到权重分配完毕。

**token类型**：
- TOKEN_START (0): 点解码起始
- TOKEN_SELECT (1): 骨骼选择（指针机制）
- TOKEN_WEIGHT (2): 权重bin标记
- TOKEN_PAD (3): 填充

**解码器架构**：
- 每个顶点独立解码，使用Transformer注意力机制
- 骨骼选择采用指针网络——Query来自解码状态，Key来自骨骼token，通过点积计算指针logit
- 权重bin通过分类头预测
- 支持教师强制训练和贪婪推理两种模式

### 5.6 特征编码器

#### 5.6.1 Mesh-Joints编码器

Mesh-Joints编码器是一个预训练的冻结模块，负责从原始网格和骨骼数据中提取特征。

**输入**：
- vertex_positions_normals [B, V, 6]：顶点位置(xyz)和法线(xyz)
- skeleton_positions [B, J, 3]：骨骼关节位置
- 其他骨骼拓扑信息

**输出**：
- vertex_features [B, V, D_v]：逐顶点特征
- bone_features [B, J, D_b]：逐骨骼特征
- vertex_global_features [B, D_b]：网格全局特征
- skeleton_global_features [B, D_b]：骨骼全局特征

#### 5.6.2 PartField编码器（可选）

PartField是一个基于3D点云的预训练特征提取器，为每个顶点提供额外的部件级语义特征。

**工作方式**：
1. 将网格顶点坐标作为点云输入
2. 提取逐点特征（隐含了部件语义信息）
3. 与Mesh-Joints编码器的顶点特征在特征维度上拼接

启用PartField后，顶点特征维度从基础的504维扩展为704维（504 + 200）。

### 5.7 训练方法

#### 5.7.1 损失函数

骨骼选择网络的训练采用标准的自回归交叉熵损失：

```
L = CrossEntropy(logits.permute(0,2,1), labels, ignore_index=-100)
```

其中logits形状为[B, L, V_size]（V_size = J + 4），labels形状为[B, L]。特殊标记位置的label设为-100（忽略索引），不参与损失计算。

#### 5.7.2 训练策略

- **数据分段**：每个训练样本通过滑动窗口切割为多个固定长度的片段，每批次随机采样segment_per_batch个片段参与训练
- **梯度检查点**：支持在Transformer层中启用梯度检查点以降低显存占用
- **OOM容错**：内置显存溢出检测和自动跳过机制，记录触发OOM的样本文件名供后续分析
- **混合精度**：全程使用bf16混合精度训练
- **优化器**：学习率1e-4，梯度范数裁剪上限1.0

#### 5.7.3 验证流程

验证时使用完整的推理流水线（BoneselectionPipeline），计算以下指标：
- 骨骼选择准确率（Top-K precision/recall）
- 蒙皮权重L1距离
- 困惑度（Perplexity）

## 六、发明的有益效果

### 6.1 自回归建模实现骨骼选择的条件依赖学习

将骨骼选择问题建模为自回归序列生成任务，使模型在生成每个顶点的骨骼选择时能够以前序顶点的选择结果为条件，有效捕获了蒙皮权重分配中的空间结构先验。例如，当模型已经为手臂近端的顶点选择了上臂骨骼和前臂骨骼，生成手臂远端顶点的选择时会自然倾向于选择相同的骨骼子集。

### 6.2 骨骼选择与权重回归的解耦级联架构

通过将骨骼选择（离散决策）和权重回归（连续预测）分离为两个独立的网络阶段，每个网络可以专注于自身任务：
- 骨骼选择网络专注于从大量候选骨骼中选择正确的子集
- 权重解码网络专注于在已知正确骨骼子集的条件下回归精确的权重值

这种解耦比端到端联合预测具有更好的可优化性和可解释性。

### 6.3 生成模型范式支持多样性采样与偏好优化

自回归生成框架使骨骼选择模型具备了生成模型的能力：
- 可以通过温度调节和Top-K采样产生多个不同的骨骼选择方案
- 不同方案经权重解码后可以进行质量评估和比较
- 天然支持DPO（Direct Preference Optimization）等偏好对齐训练范式
- 为蒙皮权重预测提供了从"判别模型"到"生成模型+偏好对齐"的范式升级路径

### 6.4 沙漏Transformer实现超长序列的高效处理

沙漏型Transformer结构通过多分辨率处理显著降低了自注意力的计算复杂度：
- Pre/Post分支在原始分辨率上使用滑动窗口注意力，复杂度为O(L × W)（W为窗口大小）
- Valley分支在1/s分辨率上处理压缩序列，有效感受野扩大s倍
- 路由缓存机制使逐token推理无需重复计算valley分支

对于典型的80000 token序列（约6000个顶点），该设计相比全注意力的O(L^2)复杂度具有数量级的效率提升。

### 6.5 灵活的序列标记化与变长适应

专用的标记化方案使系统能够自然地处理任意顶点数和骨骼数的三维网格：
- 词表大小随骨骼数动态调整，无需固定大小的输出层
- 滑动窗口切割支持对超长网格的训练，且保证每个窗口包含完整的顶点骨骼组
- 每个顶点的骨骼数可以变化（1到K之间），由SEP标记自然分隔

### 6.6 Beam Search与多策略解码

支持贪婪采样、温度采样和束搜索多种解码策略：
- 贪婪采样适用于快速推理场景
- 温度采样用于生成多样化候选方案（DPO训练）
- 束搜索用于寻找全局最优方案（质量优先场景）

多种解码策略的共存使系统能够根据不同的应用场景灵活切换。

3. **偏好对构建**：根据质量指标，在N个方案中选取质量最高的作为"偏好"（preferred）方案，质量较低的作为"拒绝"（rejected）方案
4. **DPO训练**：利用自回归模型对每个方案的对数概率，按DPO损失函数优化策略模型，使模型倾向于生成更高质量的骨骼选择

## 九、权利要求

### 权利要求1
一种基于自回归Transformer的三维角色骨骼选择方法，其特征在于，包括以下步骤：
- S1：将三维网格的骨骼选择问题转化为一维序列生成问题，定义包含特殊标记（PAD、BOS、EOS、SEP）和骨骼标记的词表；
- S2：将每个顶点关联的骨骼按权重降序排列，用分隔标记连接各顶点的骨骼列表，形成完整的骨骼选择token序列；
- S3：通过沙漏型因果Transformer网络，以自回归方式逐token生成骨骼选择序列，其中每个token的生成以前序所有token为条件；
- S4：将生成的token序列通过反向标记化还原为骨骼选择矩阵。

### 权利要求2

## 十、摘要

本发明公开了一种基于沙漏自回归Transformer与级联权重解码器的三维角色骨骼蒙皮方法及系统。该方法首先将三维网格的骨骼选择问题转化为一维序列生成问题，通过定义包含特殊标记和骨骼标记的词表，将每个顶点的骨骼选择编码为token序列。核心网络采用沙漏型因果Transformer架构，通过多分辨率处理（Pre-Valley-Post三阶段）和滑动窗口注意力机制实现对超长序列的高效自回归生成。网络采用双通道混合嵌入策略，在嵌入空间中结构化融合顶点特征和骨骼特征。生成的骨骼选择经级联权重解码器转化为连续蒙皮权重。本发明的自回归生成框架天然支持多样性采样，可产生多个候选方案用于DPO偏好优化训练，为骨骼蒙皮预测提供了从判别模型到生成模型的范式升级。
