# 专利 1（独立硬核）：基于稀疏雅可比矩阵的反向蒙皮权重求解器

## 1) 名称候选
- 一种基于稀疏雅可比矩阵的反向蒙皮权重求解方法、装置及存储介质
- 一种用于线性蒙皮的顶点位移到骨骼权重的稀疏优化求解方法

## 2) 技术问题（要写清）
- 现有反向修正权重常用梯度下降/迭代优化，收敛慢、耗时高，难满足生产交互/批处理时延要求
- 长尾 case（如裙摆）需要“确定性可控”的权重回写，避免概率性波动带来的扭曲/不可修

## 3) 核心创新点（必须在独权里体现）
- 从 LBS/线性蒙皮公式出发，构建“顶点位移→权重变化”的数学映射
- 构建**稀疏雅可比矩阵**：仅保留“受影响顶点—相关骨骼”的邻接结构，减少未知量与约束规模
- 将慢速迭代优化转化为**一次性求解**（闭式/线性最小二乘/二次规划 QP），达到毫秒级或显著加速
- 支持约束条件（权重非负、和为 1、骨骼数上限、局部性约束）保证可落地

## 4) 输入 / 输出（交底书必备）
**输入：**
- 骨骼层级与变换（bind pose、当前 pose）
- 网格拓扑（顶点、边、面）、顶点坐标
- 初始权重（或初始绑定结果）
- 目标顶点位移 / 目标几何（来自平滑或人工修正）
- 受影响区域（顶点子集）与候选骨骼子集（可由规则/指标生成）

**输出：**
- 权重增量或更新后的权重集合
- 可选：修正后的绑定结果、质量指标变化、求解日志（用于回归）

## 5) 方法流程（建议写成 6–8 步）
1. 获取目标区域顶点集合与候选骨骼集合（由阈值/邻接规则确定）
2. 基于 LBS 建立顶点位移与权重变化之间的线性化关系
3. 构建雅可比矩阵 J，并基于邻接规则构建其稀疏结构
4. 构建目标函数：拟合误差项 + 正则项（稀疏/平滑/幅度限制）
5. 加入约束：非负、和为 1、骨骼数限制、局部约束等
6. 选择求解方式：线性最小二乘 / QP / 带约束的最小二乘
7. 输出权重更新并回写至生产管线
8. 计算修正后质量指标（可选）并记录

## 6) 关键设计细节（容易形成从属权利要求）
- 稀疏化策略：骨骼候选集合如何选（距离阈值、权重阈值、层级祖先、邻接骨骼）
- 顶点候选集合如何选（异常区域、曲率/共线、布线扭曲区域）
- 正则项设计：L2、L1、邻接顶点权重差、骨骼权重变化幅度惩罚
- 约束策略：投影法、罚函数、拉格朗日乘子、主动集等
- 分块/并行求解：按连通域拆分、按骨骼簇拆分

## 7) 可量化效果（写在“有益效果”）
- 相比基于梯度下降的慢速迭代，推理/求解加速显著（例如 50 倍级）
- 运算达到毫秒级，支持生产自动算子与交互闭环
- 通过稀疏结构降低内存与计算复杂度，提高稳定性

## 8) 需要补齐/准备的材料清单（你们写交底书时最缺的）
- LBS 公式、线性化推导（1–2 页即可）
- 稀疏结构构建规则的明确定义（伪代码/流程图）
- 一个最小可复现实例（10–30 个顶点、2–6 根骨骼，展示求解前后权重变化）
- 与迭代法对比：耗时、误差、稳定性（至少 1 张表）

# 专利 2（平台型）：无 GT 的物理规则自动评估与数据闭环系统

## 1) 名称候选
- 一种在缺少真值标注下的蒙皮质量自动评估、异常筛选与训练数据构建方法
- 一种基于物理规则的蒙皮结果自动评分与数据清洗系统

## 2) 技术问题
- 蒙皮质量评估缺少 GT（难标注、成本高），导致：
  - 无法自动回归与监控
  - 数据清洗依赖人工，慢且不稳定
  - 训练/微调难以针对问题区域定向提升

## 3) 核心创新点（建议把“系统闭环”写进独权）
- 在无 GT 条件下，利用几何/物理规则构建**多指标质量评估**
- 支持从蒙皮结果中自动识别异常：布线、穿插、粘连、能量异常、共线等
- 基于评分与阈值策略自动输出：异常样本、异常类型标签、可用于训练/微调的数据集
- 支持扩展为 RL 奖励模型/在线质量闸门（作为从属或实施例）

## 4) 输入 / 输出
**输入：**
- 模型输出的蒙皮结果（顶点轨迹/骨骼变换/权重）
- 网格拓扑与分部件信息（头发、躯干、布料等可选）
- 指标配置（阈值、权重、聚合策略）

**输出：**
- 单样本评分、各指标分数
- 异常样本列表（可含异常类型：穿插/粘连/共线/能量异常）
- 数据清洗结果：保留/剔除/重加权
- 可选：训练数据构建策略（采样权重、难例挖掘）

## 5) 方法流程（建议 7–9 步）
1. 解析输入的蒙皮结果与拓扑信息
2. 计算多指标：共线/穿插/粘连/能量等（指标可插拔）
3. 指标归一化与跨样本对齐（长度、顶点数、部位差异）
4. 多指标聚合为总分（加权和/规则树/学习型阈值）
5. 异常定位（顶点/边/面/骨骼影响域）与异常分类
6. 输出异常样本与可解释报告（用于美术/工程）
7. 基于异常结果进行数据清洗（剔除/重采样/标记）
8. 与训练联动：微调/损失调制/难例提升
9. 回归监控：版本对比与趋势统计（可选）

## 6) 关键细节（从属权利要求来源）
- 阈值策略：固定阈值、分位数阈值、按部位自适应阈值
- 聚合策略：规则优先级、门控机制、异常投票机制
- 异常定位：连通域、骨骼影响域反推、局部区域扩张
- 数据闭环：异常样本自动入库、触发微调、触发回归

## 7) 可量化效果（示例写法）
- 自动筛出一定比例异常样本，误判率可控，显著节省人工评估
- 通过异常驱动的定向微调提升关键部位准确率并减少穿插粘连

## 8) 需要准备的材料
- 指标列表与定义（至少 3 个）
- 评分聚合公式/伪代码
- 清洗前后对比：异常占比、误判率、人工节省、模型提升（表格）

# 专利 3（指标型）：基于分离轴定理（SAT）的共线/形变异常检测指标

## 1) 名称候选
- 一种基于分离轴定理的蒙皮共线与局部形变异常检测方法
- 一种用于角色蒙皮结果的共线/翻折异常自动判定方法

## 2) 技术问题
- 头发/布料/细长结构在运动中易出现共线、挤压、翻折等异常
- 人工肉眼筛查成本高，且一致性差

## 3) 核心创新点
- 将蒙皮结果的局部几何片段映射为可判定对象（例如边链、局部面片、骨骼影响区域）
- 基于 SAT 投影与分离条件构建“共线/形变异常”的可计算指标
- 支持跨帧累计，区分瞬时误差与持续异常

## 4) 输入 / 输出
**输入：**
- 顶点位置（单帧或多帧序列）
- 局部结构（边链/面片/分组）
- 阈值配置（角度、投影重叠度、距离等）

**输出：**
- 共线分数/异常标记
- 异常区域定位（顶点集合/边集合）
- 异常持续性统计（跨帧）

## 5) 方法流程（建议 5–7 步）
1. 选取检测对象（边链/局部面片/骨骼影响域）
2. 构建候选分离轴集合（法线/边方向/主方向等）
3. 对对象在各轴上做投影并计算重叠/分离程度
4. 结合角度/曲率/长度变化判定共线或翻折类型
5. 输出异常分数与定位结果
6. 多帧聚合得到持续性评分（可选）

## 6) 需要准备的材料
- 检测对象定义（非常关键：怎么选、怎么分组）
- 轴集合定义与阈值建议
- 1–2 个典型异常案例的可视化截图/说明（内部用即可）

# 专利 4（指标型）：穿插/粘连自动检测指标与快速判定方法

## 1) 名称候选
- 一种用于角色蒙皮结果的穿插与粘连自动检测方法
- 一种基于拓扑分组与时序一致性的穿插/粘连判定方法

## 2) 技术问题
- 头发/布料与身体或彼此之间易发生穿插、粘连
- 单纯碰撞检测误报多，且难区分“近距离正常接触”与“粘连错误”

## 3) 核心创新点（建议写入独权的“组合判定”）
- 使用加速结构（BVH/包围盒/近邻搜索）实现批量快速检测
- 将“穿插”定义为：几何体相交 + 深度/面积/持续帧数达到阈值
- 将“粘连”定义为：持续近距离 + 相对运动一致性/法线夹角一致性 + 拓扑分组约束
- 输出可解释的异常类型与位置，直接用于清洗与质量闸门

## 4) 输入 / 输出
**输入：**
- 网格拓扑与分部件分组（头发/躯干/布料/附件等）
- 顶点位置（单帧或序列）
- 阈值配置（距离阈值、持续帧数、法线夹角、相对速度阈值等）

**输出：**
- 穿插分数、粘连分数
- 异常定位：相交面片对/顶点对/区域连通域
- 异常统计：持续时间、最大深度、面积占比等

## 5) 方法流程（建议 7–9 步）
1. 构建检测对象与分组（避免同组自检或定义可检集合）
2. 构建加速结构（BVH/网格哈希/近邻索引）
3. 穿插检测：候选对筛选 → 精确相交判定 → 深度/面积计算
4. 粘连检测：近距离对筛选 → 相对运动/法线一致性判定 → 持续性累计
5. 异常区域聚类（连通域/空间聚类）
6. 输出异常类别与定位结果
7. 与数据清洗/质量闸门联动（可选）

## 6) 需要准备的材料
- 具体阈值或阈值自适应规则（至少给一个默认配置）
- “粘连”区别于“正常接触”的判定逻辑（核心卖点）
- 典型案例：粘连 vs 正常接触、穿插深度示例

# 专利 5（闭环型）：面向长尾布料的确定性后处理（平滑-映射-回写）

> 注意：本专利不以“稀疏雅可比反求”为核心（避免与专利 1 重叠）。  
> 核心应是：**异常区域定位 + 几何平滑目标生成 + 权重/参数回写策略**。

## 1) 名称候选
- 一种面向长尾布料蒙皮的几何平滑与权重回写的确定性后处理方法
- 一种基于异常定位的裙摆/布料蒙皮稳定化后处理方法

## 2) 技术问题
- 长尾布料（裙摆等）出现概率性布线扭曲，影响生产确定性
- 美术需要一键可用且结果稳定、可控、可回归的闭环后处理

## 3) 核心创新点
- 从异常检测/规则触发定位不平滑区域（共线、曲率突变、能量高等）
- 基于 Laplacian/曲率约束等几何平滑生成“期望几何”
- 通过局部回写策略将几何修正稳定映射回权重/骨骼参数，并限制影响域保证可控
- 封装为后台自动算子，静默集成至生产功能

## 4) 输入 / 输出
**输入：**
- 初始蒙皮结果（顶点、权重、骨骼变换）
- 异常区域定位结果（可来自专利2/3/4）
- 平滑参数（平滑强度、边界约束、保持体积/长度等）
- 回写策略参数（影响域、骨骼子集、权重变化幅度限制等）

**输出：**
- 平滑后的目标几何（中间结果，可选）
- 更新后的权重/骨骼参数
- 最终可生产的稳定蒙皮结果
- 可选：前后对比指标与日志

## 5) 方法流程（建议 8–10 步）
1. 读取蒙皮结果并获取布料/裙摆区域
2. 根据规则/指标定位异常区域（共线、扭曲、能量异常等）
3. 扩张与裁剪异常区域（连通域、边界保持）
4. 构建几何平滑目标函数（Laplacian/曲率/边界约束）
5. 求解得到平滑后的目标顶点位置（期望几何）
6. 定义回写目标与约束（局部性、幅度限制、边界不动等）
7. 将几何修正映射为权重/参数更新（可调用任意求解器实现）
8. 回写并生成最终蒙皮结果
9. 验证稳定性（穿插/共线/能量等指标回归）
10. 输出为后台自动算子并集成生产流程

## 6) 关键细节（从属权利要求来源）
- 异常区域定位方式：阈值、分位数、自适应阈值、跨帧累计
- 平滑方式：Laplacian、曲率流、带边界固定的平滑、保持长度/体积约束
- 回写策略：局部骨骼子集限制、权重变化幅度限制、连通域分块处理
- 稳定性验证：至少 2 个指标闭环（例如共线 + 穿插）

## 7) 需要准备的材料
- 典型“裙摆扭曲”输入输出对比（截图/视频帧/指标变化）
- 平滑目标函数/约束定义（公式或伪代码）
- 回写策略的限制规则（影响域与幅度限制如何保证“确定性”）

# 五件专利之间的边界与避免重叠建议（写交底书时很关键）
- **专利1**：核心是“稀疏雅可比 + 一次性求解权重”，不强调异常定位与平滑
- **专利2**：核心是“无GT多指标评估 + 数据清洗/闭环系统”，指标可插拔
- **专利3/4**：核心是“指标定义与计算流程”，避免写成完整数据闭环（那是专利2）
- **专利5**：核心是“异常定位触发 + 平滑目标 + 回写策略”，求解器仅作为可选实现（可引用专利1）
